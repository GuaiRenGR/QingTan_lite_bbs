## Project Overview

轻坛 QingTan (ForumX Lite) — a mobile-first BBS forum system with a Flutter client and a raw PHP server designed for shared hosting (no Composer, no framework, no Redis).

## Flutter Client (`hjyz_bbs/`)

### Build & Run

```bash
cd hjyz_bbs
flutter pub get
flutter run                      # default device
flutter run -d windows           # Windows desktop
flutter run -d chrome            # Web
flutter build apk                # Android release
flutter analyze                  # static analysis
flutter test                     # run tests
```

Generate launcher icons: `flutter pub run flutter_launcher_icons`

### Architecture

- **State management**: Riverpod (`flutter_riverpod`) — providers defined with `StateNotifierProvider`, consumed via `ConsumerStatefulWidget` / `ref.watch` / `ref.read`
- **Routing**: GoRouter (`go_router`) — all routes defined in `lib/router.dart`; uses path parameters (`:id`) and query parameters
- **HTTP client**: Dio (`dio`) — singleton `ApiClient.instance` in `lib/core/api/api_client.dart`; all requests go to `index.php?route=<route_name>`; auth token injected via interceptor from `flutter_secure_storage`
- **API response format**: `{ code: 0, message: "...", data: ... }` — code 0 = success; wrapped in `ApiResult<T>` (see `lib/core/api/api_result.dart`)
- **API base URL**: hardcoded in `lib/core/config/app_config.dart` (`AppConfig.apiEntry`)

### Feature Modules (`lib/features/`)

Each feature is a self-contained directory with its page(s), widgets, controller/state, and repository:

- `auth/` — login, register, `AuthController` (Riverpod StateNotifier, global `authControllerProvider`)
- `home/` — feed page, waterfall thread grid
- `thread/` — thread detail, create/edit thread, BBCode content rendering
- `main/` — bottom tab shell (Home, Dynamic, Post, Discover, Me)
- `me/` — profile page, settings
- `search/`, `history/`, `creator/`, `profile/`, `user/`, `checkin/`, `discover/`, `dynamic/`, `message/`

### Content Format

Posts use a custom BBCode-like format: `[img=url]`, `[video=url]`, `[url=...]text[/url]`, `[hide]...[/hide]`. The `ForumContentView` widget (`lib/features/thread/widgets/forum_content_view.dart`) parses and renders these tags.

### Key Widgets

- `ThreadWaterfallGrid` — staggered grid layout for thread cards (uses `flutter_staggered_grid_view`)
- `ForumContentView` — BBCode content renderer
- `ForumVideoPlayer` — video playback via `media_kit`
- `XhsImagePager` — image viewer (Xiaohongshu-style)

## PHP Server (`server/`)

### Architecture

No framework. Pure PHP with a manual router in `index.php`. Designed for shared hosting where only file upload is available.

- **Entry point**: `index.php` — reads `$_GET['route']` and dispatches to controller static methods via a switch statement
- **Autoloader**: PSR-4 style for `App\Controllers\` namespace, mapping to `app/Controllers/`
- **Database**: `core/Database.php` — static PDO wrapper; config from `config/database.php` (generated by `install.php`); table prefix support via `Database::table('name')`
- **Auth**: `core/Auth.php` — Bearer token auth; tokens hashed with SHA-256 and stored in `user_tokens` table; 30-day expiry
- **Request/Response**: `core/Request.php` (input parsing), `core/Response.php` (JSON output with `code`/`message`/`data` envelope)
- **File uploads**: stored on OneDrive via `core/OneDriveService.php`; config in `config/onedrive.php`
- **Helpers**: `core/helpers.php` — content sanitization, tag management, history tracking, daily stats

### Installation & Upgrades

- `install.php` — browser-based installer (creates tables, `config/database.php`, admin user)
- `upgrade_*.php` — incremental migration scripts (run each in order via browser)
- `server.zip` — pre-packaged deployable archive
- `config/onedrive.php` — OneDrive file storage config (must be set manually); `config/database.php` is auto-generated by `install.php`

### API Routes

All routes go through `index.php?route=<name>`. Controllers in `app/Controllers/`:

- `auth/*` — register, login, logout, me (AuthController)
- `home/feed` — main feed (HomeController)
- `threads/*` — detail, create, update, delete, like/unlike, favorite/unfavorite, share, report, recommend (ThreadController, ThreadCreateController, ThreadActionController, ThreadManageController, ThreadReadController)
- `posts/*` — list, create (PostController)
- `forums/*` — list, detail, threads (ForumController)
- `user/*` — profile, follow/unfollow, threads, posts, favorites (UserController)
- `search/*` — threads, hot (SearchController)
- `history/*` — list, delete, clear (HistoryController)
- `profile/*` — get, update (ProfileController)
- `creator/*` — summary, threads (CreatorController)
- `checkin/*` — status, do (CheckinController)
- `messages/*`, `conversations/*` — private messaging (MessageController)
- `notifications/*` — notification list, read, settings (NotificationController)
- `tags/*` — tag listing, threads by tag (TagController)
- `likes/*` — like status check (LikeController)
- `upload/media`, `attachments/*` — file upload and attachment management (UploadController, AttachmentController, FileController)
- `captcha/image` — CAPTCHA generation (CaptchaController)
- `app/version/check` — version check (AppVersionController)
- `recommend/*` — recommended threads (RecommendController)

### Server Response Format

```json
{ "code": 0, "message": "success", "data": {}, "request_id": "..." }
```

`code: 0` = success, non-zero = error.

## Important Notes

- The app is in Chinese (Simplified). All UI text, error messages, and API messages are in Chinese.
- Content uses custom BBCode tags, not Markdown or HTML.
- The server targets PHP 7.4+ with MySQL/MariaDB. No extensions beyond PDO required.
- Flutter SDK requirement: `^3.11.1` (see `pubspec.yaml`).
- Flutter test suite is the default scaffold (`test/widget_test.dart`) — no comprehensive tests exist yet.
- The `core/` directory under `lib/` contains shared infrastructure: `api/` (Dio client, ApiResult), `config/` (AppConfig), `services/`, `storage/` (token persistence), `widgets/`.
