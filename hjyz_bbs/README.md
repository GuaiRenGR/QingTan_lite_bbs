# 轻坛 - Flutter 客户端

轻坛社区 Flutter 客户端，支持 Android、iOS、Windows、macOS、Linux、Web。

## 功能模块

| 模块 | 说明 |
|------|------|
| auth | 登录、注册 |
| checkin | 每日签到 |
| creator | 创作者中心 |
| discover | 发现页 |
| history | 浏览历史 |
| home | 首页（推荐/热门/精华/最新）、支持回复/转发/点赞/分享的管理员 X 风格信息流 |
| main | 底部导航框架 |
| me | 个人中心、设置 |
| message | 私信聊天 |
| post | 发帖（文字、图片、视频、Markdown） |
| profile | 编辑资料 |
| search | 搜索帖子、用户 |
| thread | 帖子详情、评论、音乐播放与歌词同步 |
| user | 用户主页 |

当前版本：1.2.3+29

## 运行

```bash
flutter pub get
flutter run
```

## 构建

```bash
# Android
flutter build apk

# Windows
flutter build windows

# iOS
flutter build ios
```
